Iris Shiny Web App

interactive data visualization 2024

This project explores the data set Iris, which comprises of measurements of iris flowers from three different species: setosa, versicolor, and virginica. Each sample consists of four features: sepal length, sepal width, petal length, and petal width. This definition was written by Geeks for Geeks. If you would like more information, please visit their website here: Geeks for Geeks.

The user is allowed to explore the relationships between the three different species and see how sepal and petal measurements differ with different data visualizations as well as several explanations that have been provided for within the application.
